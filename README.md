# C++ Numeric Analyzer & Statistics Utility

A simple yet effective C++ command-line tool designed to handle dynamic input data using standard vectors, perform arithmetic summations, averages, and execute mathematical operations leveraging the `<cmath>` library.

## [+] Features
- **Dynamic Data Ingestion:** Utilizes `std::vector` to store a custom number of user-defined inputs.
- **Statistical Computations:** Automatically calculates total sum and arithmetic mean.
- **Mathematical Processing:** Applies square root operations (`sqrt`) to both aggregated totals and averages.
- **Structured Console Output:** Clean formatted report displaying processing metrics.

## [+] Tech Stack
- **Language:** C++
- **Key Concepts:** Vectors, Loops (`for`), Control Flow, Basic Arithmetic, and `<cmath>`.

##  How to Run (bash)?

1. Clone the repository:
   
   ```git clone https://github.com/0xJorgeSec/num-analyzer-cpp.git```

2. Compile the source code using a C++ compiler (like g++):

```g++ main.cpp -o analyzer```

3. Execute the program:


```./analyzer```
